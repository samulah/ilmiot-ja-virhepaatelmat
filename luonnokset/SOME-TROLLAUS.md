# Somesisältö: Trollaus ja keskustelun sabotointi

Luonnos 3.10.2026 · X / Threads / Bluesky · **ei julkaistu**

Lähde: `kategoria-trollaus-ja-keskustelun-sabotointi.html` ja ilmiösivut 149–165.
Tavoite on viedä sivujen vastakeinot sinne, missä trollaus tapahtuu — muodossa,
jota voi käyttää kesken ketjun.

## Käyttöohje

- **Yksi koodilohko = yksi viesti.** Ketjun viestit julkaistaan järjestyksessä,
  kukin vastauksena edelliseen.
- **Jokainen viesti on enintään 280 merkkiä linkki mukaan luettuna** (X 280,
  Bluesky 300, Threads 500), joten sama teksti käy kaikkiin kolmeen.
- **Linkit** ovat muodossa `https://www.ilmiöt.fi/…`. Tarkista ensimmäisellä
  julkaisulla, että ö-domain muuttuu klikattavaksi linkiksi. Jos ei, vaihda
  `https://www.xn--ilmit-mua.fi/…` — viestit mahtuvat rajaan silläkin.
- **Esimerkkirepliikit** ovat ilmiösivuilta tai keksittyjä. Niitä ei vaihdeta
  oikeisiin viesteihin eikä kuvakaappauksiin.

### Kuusi sääntöä tilille

1. **Toisto ja suunta, ei yksittäinen repliikki.** Jokaisessa temppuketjussa on
   aito vastine. Ilman sitä opetetaan leimaamista.
2. **Trolli haluaa reaktion, maalittaja vetäytymisen.** Kaksi eri ohjetta.
3. **Kohde on yleisö, ei trolli.** Vastaa kerran, älä jatka.
4. **Nimeä tekniikka, älä kumoa väitteitä yksi kerrallaan.** Oikaisu ei skaalaudu.
5. **"Sinäkin", ei "ne".** Useimmat trollikommentit kirjoittaa tavallinen ihminen
   huonona päivänä.
6. **Tili ei itse dunkkaa.** Ei lainausviestejä toisten viesteistä, ei oikeita
   tilejä esimerkkeinä, ei kauhistelujakoja.

## 1. Aloitusketju

Kiinnitettäväksi profiiliin. Kategoriasivun viisi kohtaa lukijalle.

```
Propaganda yrittää muuttaa sitä, mitä ajattelet. Trollaus tavoittelee vähempää ja saa usein enemmän aikaan: se tekee keskustelusta mahdottoman.

Viisi asiaa, jotka auttavat.
```

```
1. Tarkista oma tilasi ennen kuin kirjoitat.

Väsymys ja valmiiksi kiehuva ketju ovat juuri se yhdistelmä, joka saa tavallisen ihmisen trollaamaan. Kokeessa ne lähes kaksinkertaistivat trollikommentit (Cheng ym. 2017).
```

```
2. Katso toistoa, älä yksittäistä kysymystä.

Lähteen kysyminen on hyve. Kahdeskymmenes lähdepyyntö ilman yhtäkään myönnytystä on taktiikka.
```

```
3. Kysy, mikä muuttaisi kantaa.

Aito keskustelija osaa vastata. Jos mikään näyttö ei riitä, keskustelu ei koske näyttöä.
```

```
4. Vastaa yleisölle, älä trollille.

Yksi asiallinen oikaisu muille lukijoille riittää. Sitä ei tarvitse puolustaa loputtomiin.
```

```
5. Erota provosointi häirinnästä.

Sivuuttaminen toimii ensimmäiseen. Toiseen tarvitaan tallentamista, moderointia ja tukea — ei neuvoa olla välittämättä.

https://www.ilmiöt.fi/kategoria-trollaus-ja-keskustelun-sabotointi.html
```

## 2. Tunnista temppu

Kymmenen ketjua, sama rakenne: repliikki → nimi → testi → aito vastine.

### 2.1 Sealioning

```
"Anteeksi, voisitko perustella? Entä tämä lähde? Ja määrittelisitkö vielä, mitä tarkoitat?"

Kohteliaasti. Kahdettakymmenettä kertaa.

Tunnistatko tempun?
```

```
Sealioning eli merileijonointi.

Lähteitä vaaditaan väsymättä — ei siksi, että kysyjä aikoisi muuttaa kantaansa, vaan koska vaatiminen kuluttaa vastaajan. Kun kohde tuskastuu, yleisö näkee asiallisen kysyjän ja vihaisen vastaajan.
```

```
Testi: onko kysyjä reagoinut yhteenkään jo annettuun vastaukseen?

Jos ei, käännä pyyntö: "Mikä näyttö muuttaisi kantasi?"

Voit myös vastata kerran kattavasti ja sanoa ääneen, ettet jatka. Perustelu jää muiden luettavaksi.
```

```
Aito vastine: useimmat lähdepyynnöt ovat aitoja, ja lähteen kysyminen on hyve. Merileijonan tunnistaa toistosta, ei yksittäisestä kysymyksestä.

https://www.ilmiöt.fi/sealioning.html
```

### 2.2 Kunhan kysyn

```
"En väitä mitään, mutta eikö tämä ole vähän kummallista? Kysyn vain, kuka tästä oikeasti hyötyy."

Tunnistatko tempun?
```

```
Kunhan kysyn (engl. just asking questions).

Väite puetaan kysymykseksi. Ajatus istutetaan, mutta kysyjä ei ole väittänyt mitään eikä joudu perustelemaan mitään. Todistustaakka kääntyy vastaajalle.
```

```
Käännä kysymys väitteeksi ja katso, kestääkö se:

"Kysytkö vai väitätkö? Jos väität, mihin perustat sen?"

Ja kun oikaiset, kerro ensin, mikä pitää paikkansa. Vihjauksen toistaminen painaa sen muistiin.
```

```
Aito vastine: aito kysyjä hyväksyy vastauksen. Taktikko toistaa saman kysymyksen toisin sanoin — ja perääntyessään kysyy, eikö enää saa edes kysyä.

https://www.ilmiöt.fi/kunhan-kysyn.html
```

### 2.3 Se oli vain vitsi

```
"Eikö täällä enää saa edes vitsailla?"

Tunnistatko tempun?
```

```
Se oli vain vitsi — ironia suojakilpenä.

Kommentti kirjoitetaan niin, että se on vakava, jos se toimii, ja vitsi, jos siitä tulee seurauksia. Joka tarttuu siihen, on huumorintajuton. Joka ei tartu, antaa sen olla.
```

```
Älä väittele siitä, oliko se hauska. Sen keskustelun trolli voittaa.

Kysy sisällöstä: "Selvä, vitsi. Mitä mieltä olet asiasta tosissasi?"
```

```
Aito vastine: huumori ja satiiri ovat arvokkaita. Kilven tunnistaa toistosta, ei yksittäisestä kärkevästä heitosta: "vitsit" osuvat aina samaan kohteeseen, ja selitys ilmestyy vasta kritiikin jälkeen.

https://www.ilmiöt.fi/vain-vitsi.html
```

### 2.4 Tone policing

```
"Hyvä pointti, mutta tuolla asenteella et vakuuta ketään. Rauhoitu ensin, sitten voidaan jutella."

Tunnistatko tempun?
```

```
Tone policing.

Viestin sisältöön ei vastata, vaan sen sävystä tehdään pääasia. Sävy muuttuu ehdoksi, joka on täytettävä ennen kuin asiaa käsitellään — ja joka ei koskaan täyty.
```

```
Katso, palataanko asiaan sävyhuomautuksen jälkeen. Jos ei, huomautus korvasi vastauksen.

Erota kaksi keskustelua: "Voin sanoa sen rauhallisemmin. Mitä mieltä olet itse asiasta?"

Sävy korjataan, ja kysymys jää pöydälle.
```

```
Aito vastine: uhkailu, nimittely ja henkilöön käyvä loukkaaminen ovat aiheellisia syitä puuttua viestiin. Tone policingista on kyse vasta, kun sävystä puhutaan asian sijasta.

https://www.ilmiöt.fi/tone-policing.html
```

### 2.5 Huolitrollaus

```
"Sanon tämän ystävänä: kannattaisiko odottaa parempaa hetkeä? Tällainen meno vain kääntää ihmiset asiaa vastaan."

Tunnistatko tempun?
```

```
Huolitrollaus (engl. concern trolling).

Asian vastustaja esiintyy sen huolestuneena kannattajana. Suora vastustaja saa vastaansa perustelut. Huolestunut ystävä saa kuulijan epäröimään, koska näyttää olevan samalla puolella.
```

```
Katso, mihin suuntaan neuvot johtavat. Huolitrollaus ehdottaa aina vähemmän: hiljempaa, hitaammin, myöhemmin, ei nyt.

Kysy suoraan: "Mikä olisi sinusta oikea tapa ajaa tätä asiaa?"

Jos vastausta ei tule, huoli ei koske tapaa vaan asiaa.
```

```
Aito vastine: kannattajien oma taktiikkakritiikki on usein aiheellista. Se ehdottaa parempaa tapaa päästä samaan tavoitteeseen. Tunnusmerkki on neuvon suunta, ei se, että joku kritisoi.

https://www.ilmiöt.fi/huolitrollaus.html
```

### 2.6 Motte and bailey

```
"Tämä tuote parantaa syövän."

Joku kysyy näyttöä.

"Tarkoitin vain, että hyvinvointi auttaa jaksamaan. Eihän siitä kukaan voi olla eri mieltä?"

Seuraavana päivänä: sama alkuperäinen väite.

Tunnistatko tempun?
```

```
Motte and bailey.

Samalla nimellä kulkee kaksi väitettä: rohkea ja kiistaton. Rohkeaa käytetään, kun kukaan ei vastusta. Haastettaessa perääntytään kiistattomaan — ja kriitikko näyttää hyökkäävän itsestäänselvyyttä vastaan.
```

```
Erota versiot ääneen. Myönnä torni ja pyydä kantaa pihaan:

"Olen samaa mieltä siitä, että hyvinvointi auttaa jaksamaan. Väitätkö myös, että tuote parantaa syövän?"
```

```
Aito vastine: se, joka tarkentaa väitettään ja sitoutuu tarkennukseen. Temppu on, että sisältö muuttuu kritiikin mukana mutta nimi pysyy samana — ja rohkea versio palaa, kun kriitikko lähtee.

https://www.ilmiöt.fi/motte-and-bailey.html
```

### 2.7 Nutpicking

```
"Katsokaa, mitä ne sanovat."

Kuvakaappauksessa on tili, jolla on kolme seuraajaa.

Tunnistatko tempun?
```

```
Nutpicking (nut + cherry-picking).

Vastapuolen hölmöin yksittäinen kommentti nostetaan koko joukon kasvoiksi. Esimerkki on aito, ja siksi sitä on vaikea kiistää. Keksitty on vain sen edustavuus.
```

```
Kysy kuka sanoi ja kuinka moni. Onko lainattu ryhmän edustaja, johtaja tai ohjelman kirjoittaja — vai satunnainen tili?

Omassa väittelyssä tee päinvastoin: kumoa vastapuolen vahvin esitys, älä heikointa.
```

```
Aito vastine: jos sanoja on ryhmän johtaja tai sen ohjelman kirjoittaja, lainaus kertoo ryhmästä. Jos esimerkkiä ei voi yhdistää kehenkään, jolla on vaikutusvaltaa, se kertoo yksilöstä.

https://www.ilmiöt.fi/nutpicking.html
```

### 2.8 Kafkatrapping

```
"Jos et olisi syyllinen, et olisi noin puolustuskannalla."

Tunnistatko tempun?
```

```
Kafkatrapping.

Syytöksen kiistäminen tulkitaan todisteeksi syyllisyydestä. Kaikki vaihtoehdot on lukittu: kiistäminen on todiste, myöntäminen tunnustus ja vaikeneminen myöntymistä.
```

```
Testi on yksi kysymys: "Mikä voisi osoittaa, että olet väärässä?"

Jos mikään ei voisi, keskustelu ei koske näyttöä. Pyydä konkreettista tekoa: mitä tein, milloin ja miten? Älä yritä todistaa sisäistä tilaasi. Sitä ei voi todistaa.
```

```
Aito vastine: joskus kiivas kiistäminen todella paljastaa jotain, ja kritiikin torjuminen kafkatrappingina on itsekin kätevä pakotie. Ero on siinä, perustuuko syytös johonkin muuhun kuin kiistämiseen.

https://www.ilmiöt.fi/kafkatrapping.html
```

### 2.9 Dunkkaus

```
Pienen tilin viesti jaetaan lainauksena suuren tilin yleisölle. Saatteena yksi pilkallinen rivi.

Tunnistatko tempun?
```

```
Dunkkaus (engl. dunking).

Vastaus ei ole tarkoitettu kirjoittajalle vaan omille seuraajille. Ratio on sen mittari, mutta se ei kerro, kuka on oikeassa, vaan kenellä on isompi yleisö.
```

```
Ennen lainaamista kysy: kenelle tämä vastaus on? Jos omille seuraajille, se on esitys, ei keskustelu.

Vastaa suoraan viestiin. Jos haluat puhua ilmiöstä etkä ihmisestä, ota kuvakaappaus ilman nimeä.
```

```
Aito vastine: kritiikki puhuu kirjoittajalle, dunkkaus hänestä muille. Yksi lainaus voi osoittaa kohteen tuhansille, vaikka lainaaja ei sitä tarkoittaisi — siksi dunkkaus on usein maalittamisen ensimmäinen askel.

https://www.ilmiöt.fi/dunkkaus.html
```

### 2.10 Shitpostaus

```
Ketjussa puhutaan tapahtuneesta vahingosta. Hetkeä myöhemmin se on täynnä meemejä, vitsejä ja sekalaisia heittoja. Asiaa on kolmessa viestissä, eikä kukaan enää löydä niitä.

Tunnistatko tempun?
```

```
Shitpostaus taktiikkana.

Tahallisen arvotonta sisältöä tuotetaan keskustelun päälle. Argumentin voi kumota, roskaa ei: se ei väitä mitään, mihin voisi tarttua. Se vain vie tilan, kunnes kirjoittaja lakkaa yrittämästä.
```

```
Testi: vaihtuiko aihe? Jos vakava ketju on muuttunut vitsailuksi, joku hyötyi siitä.

Älä vastaa roskaan roskalla. Jos asia on tärkeä, kirjoita se omaksi viestikseen, jonka voi linkittää ja johon voi palata.
```

```
Aito vastine: suurin osa shitpostauksesta on harmitonta sisäpiirin huumoria, jolla ei ole mitään tavoitetta. Harmitonta se on niin kauan kuin se pysyy omassa ketjussaan.

https://www.ilmiöt.fi/shitpostaus.html
```

## 3. Taustaketjut

### 3.1 Miksi ihmiset trollaavat ("sinäkin")

Julkaistaan ennen temppuketjuja: se asettaa sävyn, jossa lukija ei ole syytetty.

```
On houkuttelevaa ajatella, että trollit ovat erillinen joukko ihmisiä.

Tutkimus antaa kaksi vastausta, ja toinen niistä on epämukava.
```

```
Ensimmäinen koskee luonnetta.

Kyselytutkimuksessa trollaamisesta nauttiminen oli yhteydessä vahvimmin arkipäiväiseen sadismiin (Buckels ym. 2014). Osalle toisen ahdistus on itse palkkio. Silloin perustelu ei auta, koska hän ei ole keskustelemassa.
```

```
Toinen koskee tilannetta.

Kokeessa huono mieliala ja valmiiksi myrkyllinen ketju lähes kaksinkertaistivat trollikommentit (Cheng ym. 2017). Tavallinen ihminen trollaa huonona päivänä ja huonossa ketjussa — ja heitä on enemmän.
```

```
Ruutu tekee siitä helppoa. Kasvokkain ilme ja äänensävy kertovat heti, meneekö jokin liian pitkälle. Verkossa tämä palaute puuttuu.

Testi itselle: sanoisinko tämän ääneen, jos hän istuisi vastapäätä?
```

```
Käytännössä: jos olet väsynyt tai ärtynyt ja ketju jo kiehuu, älä kommentoi nyt. Kirjoita kiukkuinen vastaus luonnokseksi ja lue se tunnin päästä.

https://www.ilmiöt.fi/kuka-tahansa-voi-trollata.html
```

### 3.2 Trolli vai maalittaja

```
"Älä ruoki trollia" on verkon vanhimpia neuvoja.

Se toimii yhteen tilanteeseen. Toisessa se toimii häiritsijän eduksi.
```

```
Provosoija: yksi tili, tavoite on huomio, kiinnostus loppuu kun vastausta ei tule.

Sivuuta. Jos haluat vastata, vastaa yleisölle: yksi lyhyt asiallinen oikaisu ilman lainausta. Älä jatka sitä.
```

```
Häirintä tai maalittaminen: monta tiliä, tavoite on kohteen vetäytyminen, jatkuu vaikka kukaan ei vastaa.

Hiljaisuus on juuri se, mitä haetaan. Tarvitaan moderointia, estoja, tallentamista ja tarvittaessa rikosilmoitus.
```

```
Siksi häirinnän kohteelle ei sanota "älä välitä". Se kuulostaa tuelta, mutta tarkoittaa usein "hoida itse".

Kysy, mitä hän tarvitsee.

https://www.ilmiöt.fi/trollin-ruokkiminen.html
```

### 3.3 Kun kohteena on ihminen

```
Kun joku joutuu verkossa joukon kohteeksi, useimmat meistä ovat sivullisia.

Mitä sivullinen, kohde ja työnantaja voivat tehdä.
```

```
Sivullinen: älä jaa maalitusviestiä edes kauhistellaksesi. Jokainen jako vie nimen tai osoitteen uusille silmille.

Lähetä kohteelle tukiviesti yksityisesti. Se auttaa enemmän kuin julkinen väittely maalittajan kanssa.
```

```
Kohde: tallenna kaikki kuvakaappauksina päivämäärineen, kerro työnantajalle heti ja tee rikosilmoitus uhkauksista.

Älä vastaa parvelle. Yksi vastaus on uusi maali.
```

```
Työnantaja: kohtele maalittamista työturvallisuusasiana, älä kohteen imago-ongelmana.
```

```
Maalittamisen tarkoitus on, että kohde jättää aiheen — ja muut näkevät, mitä siitä seuraa. Siksi sivustakatsojan hiljaisuus ei ole neutraalia.

https://www.ilmiöt.fi/maalittaminen.html
```

## 4. Vastausfraasit

Yksittäisiä viestejä, ei ketjuja. Julkaistaan vastaavan temppuketjun jälkeen
kertauksena. Fraasi ei ole lyömäase: sitä käytetään vasta, kun toisto on nähty.

```
Kun lähdepyyntöjä tulee loputtomasti eikä yksikään vastaus riitä:

"Mikä näyttö muuttaisi kantasi?"

Aito kysyjä osaa vastata.

https://www.ilmiöt.fi/sealioning.html
```

```
Kun väite tulee kysymyksen muodossa:

"Kysytkö vai väitätkö? Jos väität, mihin perustat sen?"

https://www.ilmiöt.fi/kunhan-kysyn.html
```

```
Kun kritiikin jälkeen kuuluu "se oli vain vitsi":
```

## 5. Ylläpitäjälle

```
Ylläpidätkö ryhmää, kanavaa tai kommenttiosiota? Neljä asiaa ketjun sävystä.
```

```
1. Ensimmäinen myrkyllinen kommentti määrää ketjun normin. Poista tai piilota se nopeasti.

Trollaus tarttuu: ensimmäinen myrkyllinen viesti tekee seuraavista todennäköisempiä (Cheng ym. 2017).
```

```
2. Siirrä tai piilota aiheen ohi menevä sisältö ennen kuin se asettaa ketjun suunnan.

Huumori on harmitonta omassa ketjussaan — ei vakavan keskustelun päällä.
```

```
3. Nosta rakentava vastaus ylös. Se tasapainottaa keskustelua paremmin kuin pelkkä poistaminen.
```

```
4. Älä lue kommenttiosion sävyä yleisösi mielipiteenä. Se on pienen aktiivijoukon mielipide.

Älä muuta linjaa kommenttivyöryn perusteella ennen kuin tiedät, edustaako se laajempaa joukkoa.

https://www.ilmiöt.fi/aanekas-vahemmisto.html
```

## 6. Prebunk-pohjat

Täytettäviä pohjia tunnettuja hetkiä varten (vaalitentti, kohu). Hakasulkeet
korvataan; **laske pituus uudelleen täytön jälkeen**. Avausviestissä ei toisteta
kumottavaa väitettä — oikaisu, joka aloittaa valheella, levittää sitä.

```pohja
[Tapahtuma] on tulossa. Sinulle tullaan sanomaan: "[tyypillinen repliikki]"

Se on [tempun nimi]: [mekanismi yhdellä virkkeellä].

Yksi testi: [testikysymys]

https://www.ilmiöt.fi/[sivu].html
```

```pohja
Kun [aihe] nousee syötteeseen, katso tekniikkaa ennen kuin katsot väitettä:

– tuleeko väite kysymyksen muodossa?
– onko esimerkki joukon edustaja vai satunnainen tili?
– hyötyykö julkaisija raivostasi?

https://www.ilmiöt.fi/inokulointiteoria.html
```

## 7. Julkaisujärjestys (ehdotus)

1. Aloitusketju, kiinnitetään profiiliin.
2. Taustaketju 3.1 ("sinäkin") — ennen yhtäkään temppua.
3. Temppuketjut 2.1–2.10 tässä järjestyksessä, yksi kerrallaan. Tutuimmat
   ensin; dunkkaus ja shitpostaus viimeisinä, koska ne johtavat seuraavaan.
4. Taustaketjut 3.2 ja 3.3 dunkkauksen jälkeen: dunkkaus on maalittamisen
   ensimmäinen askel, ja ketjut jatkavat siitä.
5. Vastausfraasit kertauksena, kukin oman temppuketjunsa jälkeen. Inokuloinnin
   suoja hiipuu, joten kertaus on osa keinoa eikä toistoa.
6. Ylläpitäjän ketju milloin tahansa; prebunk-pohjat vain tapahtuman edellä.

## Muut osat

- **Jakokuvat: tehty.** Jokaisella näissä viesteissä linkitetyllä sivulla on oma
  kuva (`og/<slug>.png`, 20 kpl), jossa on ilmiön nimi ja yhden virkkeen kuvaus.
  Linkin esikatselu kertoo siis tempun ilman klikkausta. Kuvat on vietävä
  palvelimelle ennen HTML-sivuja, tai esikatselu on tyhjä.
- **Pikaopas: luonnos.** `mita-vastata-trollille.html` kokoaa samat vastakeinot
  yhdeksi sivuksi, jonka voi pudottaa ketjuun. Kun se on julkaistu, aloitusketjun
  viimeisen viestin linkin voi vaihtaa siihen.
- **Pelikohdat: luonnos.** `pelidata/`: 60 kohtaa Vedätys-peliin. Julkaisu
  vaatii päätöksen erien uudelleenkokoamisesta, ks. `index.html`.
